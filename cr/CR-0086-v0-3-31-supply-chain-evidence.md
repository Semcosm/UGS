## Summary

Publish the deterministic v0.3.31 bootstrap archive evidence after the signed
tag exists. Restore the active high-trust supply-chain declaration and bind it
to the immutable v0.3.31 tag target.

## Motivation

The v0.3.31 tag target intentionally uses the validated basic staging profile:
evidence naming the tag target cannot be committed before the tag without a
hash cycle. The post-tag record adds the SPDX SBOM, reproducible build record,
signed ugs-attestation, and active evidence paths on main.

## Risk

The release tag is immutable and its basic staging policy remains historical
tag evidence. The active main policy is restored to high-trust only after the
tag target and artifact digest are fixed. Evidence is generated by the local
trusted builder and does not claim hosted CI signing.

## Rollback

evidence objects. If an evidence file is defective, correct the active policy
through a new signed CR and publish a later superseding patch release.
