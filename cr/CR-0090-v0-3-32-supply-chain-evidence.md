## Summary

Publish the deterministic v0.3.32 bootstrap archive evidence after the signed
tag exists. Add the SPDX SBOM and reproducible build record plus a signed
`ugs-attestation`, then restore the active high-trust supply-chain declaration.

## Motivation

The v0.3.32 tag target intentionally uses the validated basic staging profile:
evidence naming the tag target cannot be committed before the tag without a
hash cycle. The post-tag record binds the immutable tag target and published
archive digest, then restores high-trust evidence paths on main.
