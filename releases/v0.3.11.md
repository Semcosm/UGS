# UGS v0.3.11

**Release status:** formal release.

**Specification:** UGS v0.3 remains the active policy and conformance
profile. This patch release adds release-attestation validation.

## Summary

Validate Git-native JSON release attestations and bind them to release tags,
commit SHA, artifact digest, builder identity, and build timestamp. Tag CI now
invokes the supply-chain release evidence validator.

## Compatibility

Attestation validation is required only by repositories that declare the
corresponding evidence paths and stronger profile. Basic declaration-only
repositories remain valid; v0.2 history and published tags are unchanged.

## Verification

Run `scripts/validate_repo.sh`, `scripts/ugs_check.sh --format json`,
`scripts/test_release_attestation.sh`, and
`scripts/validate_release_attestation.sh` against a fixture. Verify this
release with `scripts/validate_release_tag.sh v0.3.11`.

## Rollback

Do not delete or replace published tags. Publish a superseding patch release
if a further correction is needed.
