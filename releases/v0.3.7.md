# UGS v0.3.7

**Release status:** formal release.

**Specification:** UGS v0.3 remains the active policy and conformance
profile. This patch release adds the optional supply-chain profile.

## Summary

Add optional `basic`, `standard`, and `high-trust` supply-chain declarations
for action pinning, SBOM coverage, reproducible-build evidence, and signed
release attestations.

## Compatibility

The profile is additive and optional. Repositories without a `supply_chain`
manifest section remain valid v0.3 repositories. v0.2 history and published
tags are unchanged.

## Verification

Run `scripts/validate_repo.sh`, `scripts/ugs_check.sh --format json`, policy
manifest fixtures, and `scripts/validate_supply_chain_profile.sh`. Verify this
release with `scripts/validate_release_tag.sh v0.3.7`.

## Rollback

Do not delete or replace published tags. Publish a superseding patch release
if a further correction is needed.
