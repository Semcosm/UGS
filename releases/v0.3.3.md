# UGS v0.3.3

**Release status:** formal patch release.

**Specification:** UGS v0.3 remains the active policy and conformance
profile. This patch clarifies its document boundary without changing
enforcement behavior.

## Summary

Publish the human-readable v0.3 policy and conformance profile, and clarify
that the v0.2 Core documents remain the historical baseline for migration.

## Compatibility

This is a documentation-only clarification. Accepted v0.2 history remains
valid, while v0.3 tooling and declarations retain their pre-1.0 compatibility
policy.

## Verification

Run `scripts/validate_repo.sh`, `scripts/ugs_check.sh --format json`, and all
CR validators. Verify this release with
`scripts/validate_release_tag.sh v0.3.3`.

## Rollback

Do not delete or replace published tags. Publish a superseding patch release
if further clarification is needed.
