# UGS v0.3.22

This release adds an end-to-end conformance gate for the baseline, standard,
and high-trust profiles.

The profile suite exercises generated consumer repositories, hooks, CR and Git
lifecycle behavior, migration and idempotence, protected refs, supply-chain
checks, trusted and revoked signers, signed release tags, and attestation
namespaces. Bootstrap release consumers now run the same full suite on a clean
runner.
