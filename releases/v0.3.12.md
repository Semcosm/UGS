# UGS v0.3.12

**Release status:** formal release.

**Specification:** UGS v0.3 remains the active policy and conformance
profile. This superseding patch release completes SSH attestation verification.

## Summary

Require actual SSH detached-signature verification for signed release
attestations, authorize the `ugs-attestation` namespace for the release
signer, and add invalid-signature coverage.

## Compatibility

Declaration-only basic repositories remain valid. Repositories claiming signed
attestation evidence must now provide a verifiable SSH signature. Existing
published tags are immutable and v0.2 history is unchanged.

## Verification

Run `scripts/validate_repo.sh`, `scripts/ugs_check.sh --format json`, and
`scripts/test_release_attestation.sh`. Verify this release with
`scripts/validate_release_tag.sh v0.3.12`.

## Rollback

Do not delete or replace published tags. Publish a superseding patch release
if a further correction is needed.
