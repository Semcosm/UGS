# UGS v0.3.6

**Release status:** formal release.

**Specification:** UGS v0.3 remains the active policy and conformance
profile. This patch release adds the optional quality profile.

## Summary

Add an opt-in quality profile with `basic` and `standard` levels. Validate
declared quality documents and executable test entry points, while keeping the
UGS Core contract unchanged for repositories that do not opt in.

## Compatibility

The quality profile is additive and optional. Repositories without a `quality`
manifest section remain valid v0.3 repositories. v0.2 history and its
compatibility boundary are unchanged.

## Verification

Run `scripts/validate_repo.sh`, `scripts/ugs_check.sh --format json`, the
policy manifest fixtures, and `scripts/validate_quality_profile.sh`. Verify
this release with `scripts/validate_release_tag.sh v0.3.6`.

## Rollback

Do not delete or replace published tags. Publish a superseding patch release
if a further correction is needed.
