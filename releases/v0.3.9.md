# UGS v0.3.9

**Release status:** formal release.

**Specification:** UGS v0.3 remains the active policy and conformance
profile. This patch release aligns supply-chain field validation across all
reference validators.

## Summary

Restrict each supply-chain manifest field to its own valid enum set, removing
false positives where one field accepted a value belonging to another field.

## Compatibility

This is a validator correctness fix. Valid v0.3 declarations remain valid;
ambiguous declarations that were previously accepted are now rejected.

## Verification

Run `scripts/validate_repo.sh`, `scripts/ugs_check.sh --format json`, and all
policy manifest fixtures. Verify this release with
`scripts/validate_release_tag.sh v0.3.9`.

## Rollback

Do not delete or replace published tags. Publish a superseding patch release
if a further correction is needed.
