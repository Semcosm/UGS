# UGS v0.3.8

**Release status:** formal release.

**Specification:** UGS v0.3 remains the active policy and conformance
profile. This patch release completes the optional P2 capability guidance.

## Summary

Add an optional repository-shape declaration for single repositories and
monorepos, submodules, generated files, and large-file handling.

## Compatibility

The declaration is additive and optional. Repositories without
`repository_shape` remain valid v0.3 repositories. v0.2 history and published
tags are unchanged.

## Verification

Run `scripts/validate_repo.sh`, `scripts/ugs_check.sh --format json`, policy
manifest fixtures, and `scripts/validate_repository_shape.sh`. Verify this
release with `scripts/validate_release_tag.sh v0.3.8`.

## Rollback

Do not delete or replace published tags. Publish a superseding patch release
if a further correction is needed.
