# UGS v0.3.5

**Release status:** formal release.

**Specification:** UGS v0.3 remains the active policy and conformance
profile. This patch release packages the completed P1 exception lifecycle
capabilities.

## Summary

Define structured, append-only exception records for bootstrap and emergency
events, including authorization, bounded validity windows, event identity, and
post-event review. Add repository validation and fixtures for the exception
lifecycle.

## Compatibility

This is pre-1.0 v0.3 work. Repositories claiming emergency capability must use
valid exception records. v0.2 manifests, commands, reports, and validator
behavior are not compatibility targets; accepted v0.2 history remains valid
and is not rewritten.

## Verification

Run `scripts/validate_repo.sh`, `scripts/ugs_check.sh --format json`, all CR
validators, `scripts/validate_exception_record.sh` for each exception record,
and `scripts/test_exception_records.sh`. Verify this release with
`scripts/validate_release_tag.sh v0.3.5`.

## Rollback

Do not delete or replace published tags. Publish a superseding patch release
if a further correction is needed.
