# UGS v0.3.2

**Release status:** formal patch release.

**Specification:** UGS v0.3 remains the active policy and conformance
profile. This patch does not change the normative contract.

## Summary

Restore the annotated release-tag ref after GitHub Actions checkout so the
release validator can inspect the signed tag object instead of a peeled commit
ref.

## Compatibility

This is a backward-compatible CI correction. Existing release tags remain
immutable and are not replaced.

## Verification

The release tag is a signed annotated tag pointing to the signed commit that
contains this workflow correction. Run
`scripts/validate_release_tag.sh v0.3.2` locally to verify the release object.

## Rollback

Do not delete or replace any existing tag. Publish another superseding patch
release if a further correction is needed.
