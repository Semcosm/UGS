# UGS v0.3.4

**Release status:** formal release.

**Specification:** UGS v0.3 remains the active policy and conformance
profile. This release packages the completed P1 evidence capabilities.

## Summary

Publish conformance levels and the profile matrix, enforce CR integrated-result
provenance and integration strategies, validate final review-trailer
inheritance, and add structured signer lifecycle metadata.

## Compatibility

This is pre-1.0 v0.3 work. New CRs may require integration-strategy and review
evidence metadata, and repositories must publish valid signer lifecycle data.
Accepted v0.2 history remains valid and is not rewritten.

## Verification

Run `scripts/validate_repo.sh`, `scripts/ugs_check.sh --format json`, all CR
validators, and the recovered-boundary signature validation. Verify this
release with `scripts/validate_release_tag.sh v0.3.4`.

## Rollback

Do not delete or replace published tags. Publish a superseding patch release
if a further correction is needed.
