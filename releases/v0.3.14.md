# UGS v0.3.14

**Release status:** formal release.

**Specification:** UGS v0.3 remains the active policy and conformance
profile. This patch release completes build-record evidence validation.

## Summary

Validate build records and bind their release tag, commit SHA, artifact digest,
builder identity, and timestamp during supply-chain release checks.

## Compatibility

Declaration-only basic repositories remain valid. Evidence-enabled profiles
gain consistent build-record checks; v0.2 history and published tags are
unchanged.

## Verification

Run `scripts/validate_repo.sh`, `scripts/ugs_check.sh --format json`, and
`scripts/test_build_record.sh`. Verify this release with
`scripts/validate_release_tag.sh v0.3.14`.

## Rollback

Do not delete or replace published tags. Publish a superseding patch release
if a further correction is needed.
