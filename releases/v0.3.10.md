# UGS v0.3.10

**Release status:** formal release.

**Specification:** UGS v0.3 remains the active policy and conformance
profile. This patch release adds evidence paths and minimum SBOM validation.

## Summary

Add repository-relative supply-chain evidence paths and validate SPDX and
CycloneDX SBOM structure, component identity, timestamps, source commits, and
release metadata.

## Compatibility

Evidence is optional for repositories using declaration-only basic profiles.
Existing v0.3 repositories and v0.2 history remain valid and unchanged.

## Verification

Run `scripts/validate_repo.sh`, `scripts/ugs_check.sh --format json`,
`scripts/test_sbom.sh`, and `scripts/validate_supply_chain_evidence.sh`.
Verify this release with `scripts/validate_release_tag.sh v0.3.10`.

## Rollback

Do not delete or replace published tags. Publish a superseding patch release
if a further correction is needed.
