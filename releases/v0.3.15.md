# UGS v0.3.15

**Release status:** formal release.

**Specification:** UGS v0.3 remains the active policy and conformance
profile. This superseding patch makes elevated supply-chain evidence
requirements consistent across validation entry points.

## Summary

`standard` and `high-trust` supply-chain profiles now require traceable SBOM,
build-record, and attestation evidence paths. The dedicated profile validator,
manifest validator, evidence validator, and release validator now agree on
this boundary. Follow-up verification strengthening now also cross-binds the
current repository, release/version metadata, and artifact digest across all
release evidence.

## Compatibility

Repositories without a supply-chain declaration and `basic` declaration-only
repositories remain valid. Repositories claiming `standard` or `high-trust`
without the required evidence paths must add them before they can pass.
v0.2 history and published tags are unchanged.

## Verification

Run `scripts/validate_repo.sh`, `scripts/ugs_check.sh --format json`, and
`scripts/test_supply_chain_evidence.sh`. Verify this release with
`scripts/validate_release_tag.sh v0.3.15` and
`scripts/validate_supply_chain_release.sh v0.3.15`.

## Rollback

Do not delete or replace published tags. Publish a superseding patch release
if a further correction is needed.
