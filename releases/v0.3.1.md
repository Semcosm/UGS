# UGS v0.3.1

**Release status:** formal patch release.

**Specification:** UGS v0.3 remains the active policy and conformance
profile. This patch does not change the normative contract.

## Summary

Correct release-tag validation in checkout environments that peel annotated tag
refs to their target commit during ref resolution. The validator now requires
an annotated tag object explicitly.

## Compatibility

This is a backward-compatible validator correction. Existing release tags are
append-only and remain unchanged.

## Verification

The release tag is a signed annotated tag pointing to the signed commit that
contains this correction. Run `scripts/validate_release_tag.sh v0.3.1` to
verify the release object locally.

## Rollback

Do not delete or replace the tag. If a further correction is needed, publish a
superseding patch release with a new signed annotated tag.
