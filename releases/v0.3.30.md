# UGS v0.3.30

**Release status:** planning packet; the formal v0.3.30 tag has not been
created.

## Summary

This packet closes the post-v0.3.29 governance audit and fixes the planning
boundary before the next feature release. It records v0.3.29 as the current
formal baseline, publishes the candidate tag distribution, and reserves
v0.3.31 for a branch-closure capability that reduces accumulated topic
branches.

The packet is documentation-only. It does not add the branch-closure command,
change the active v0.3 policy, or alter any existing release object.

## Included scope

- update the v0.3 roadmap baseline from v0.3.28 to v0.3.29;
- mark the Phase A-F grouping from CR-0070 as a historical, non-normative
  planning draft pending manual review;
- publish the post-v0.3.29 candidate tag distribution audit;
- publish the v0.3.31 branch-closure design; and
- register the new roadmap and release documents in the generated document map.

## Compatibility

The active policy remains policy_version: 0.3, with the existing continuous
branch profile, rebase-ff integration, protected main, and high-trust signed
release requirements. No consumer command or validator behavior changes in this
packet.
