# UGS v0.3.18

**Release status:** formal patch release.

**Specification:** UGS v0.3 remains the active policy and conformance
profile. This superseding patch corrects release-runner restoration of signed
annotated tags before publishing bootstrap assets.

## Summary

The `ugs-release` workflow now explicitly restores the annotated tag ref after
checkout. This ensures `validate_release_tag.sh` can verify the actual signed
tag object instead of seeing only the commit selected by the tag event.

The generated baseline bootstrap package and its remote consumer verification
are unchanged from v0.3.17.

## Compatibility

No repository format or bootstrap package format changes. Consumers should use
v0.3.18 for the first successful published bootstrap asset set; v0.3.17 is
retained as an auditable failed publication attempt and must not be replaced.

## Verification

The tag workflow must pass release-tag validation, bootstrap package tests,
asset publication, and the clean-runner Release consumer test. Verify the
published tag and asset checksum with:

```bash
scripts/validate_release_tag.sh v0.3.18
gh release download v0.3.18 --pattern 'ugs-bootstrap-v0.3.18*'
sha256sum -c ugs-bootstrap-v0.3.18.tar.gz.sha256
```

## Rollback

Do not delete or replace v0.3.18. If the remote consumer fails, leave the
release immutable and publish a later patch after correcting the workflow.
