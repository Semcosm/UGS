# UGS v0.3.26

This superseding patch release closes bootstrap package dependency gaps and
makes the downloaded release self-contained for offline UGS use.

## Summary

The baseline bootstrap profile now includes the Core
`scripts/validate_ref_update.sh` validator alongside the bare-Git update
adapter. The GitHub CR compatibility wrappers now explain how to install the
optional adapter when they are used in a baseline repository.

The `ugs-bootstrap-v0.3.26.tar.gz` asset also includes offline copies of the
UGS Core, v0.3 profile, conformance, branch, commit, review, release, quality,
supply-chain, repository-shape, Document Map, and bootstrap guidance under
`docs/git/`, plus `CONTRIBUTING.md` and `RELEASE.md`. The package manifest
contains checksums for every included file.

## Compatibility

No existing release tag or bootstrap package format is changed. Baseline
initialization remains GitHub-adapter-free; standard and high-trust profiles
continue to install the optional GitHub adapter. The additional documentation
files are additive and do not change initialized repository behavior.

## Verification

Before tagging, run:

```bash
scripts/validate_repo.sh
scripts/ugs_check.sh --format json
scripts/test_bootstrap_package.sh
scripts/test_bootstrap_equivalence.sh
scripts/test_profile_conformance.sh
scripts/test_bare_git_update.sh
scripts/validate_commit_range.sh v0.3.25..HEAD
scripts/validate_commit_signatures.sh v0.3.25..HEAD
```

Verify the signed release object and asset after publication:

```bash
scripts/validate_release_tag.sh v0.3.26
sha256sum -c ugs-bootstrap-v0.3.26.tar.gz.sha256
```

After extracting the archive, start with `README.md` and
`docs/git/ugs-bootstrap.md`; all referenced UGS usage guidance is available in
the archive without requiring web access.

## Rollback

Do not delete, replace, or force-update `v0.3.25` or `v0.3.26`. If a published
asset is defective, leave the tag immutable and publish a later superseding
patch release after correcting the package or workflow.
