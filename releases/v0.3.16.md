# UGS v0.3.16

**Release status:** formal release.

**Specification:** UGS v0.3 remains the active policy and conformance
profile. This patch strengthens release evidence binding and preserves trusted
signature provenance across GitHub rebase integration.

## Summary

Release validation now independently enforces elevated-profile evidence,
matches attestations to the current repository, and cross-checks release tag,
commit, version, and artifact digest across SPDX/CycloneDX SBOMs, build
records, and attestations. The policy Schema expresses the same profile and
evidence constraints. Workflow action pinning is checked against actual
workflow references.

The main-branch signature validator recognizes a GitHub-generated rebase copy
only when its tree, parents, author, and message exactly match a separately
available trusted SSH-signed source commit. Ordinary unsigned commits remain
rejected.

## Compatibility

Basic declaration-only repositories remain valid. Repositories claiming
`standard` or `high-trust` must provide complete, mutually consistent release
evidence. The v0.3 Core policy and previously accepted history are unchanged.

## Verification

The main-branch `ugs-validate` workflow passed after integration. Local
verification included `scripts/validate_repo.sh`,
`scripts/ugs_check.sh --format json`, commit-range and signature validation,
CR validation, release evidence fixtures, action-pinning fixtures, and
`git diff --check`.

Verify this release with `scripts/validate_release_tag.sh v0.3.16` and
`scripts/validate_supply_chain_release.sh v0.3.16`.
