# UGS v0.3.0

**Release status:** adoption complete; no formal `v0.3.0` tag exists yet.

**Specification:** v0.3 policy and conformance profile are active; v0.2
history remains valid as historical compatibility context.
**Adoption scope:** v0.3 manifest, conformance, CR evidence, review trailers,
release-tag validation, and protected-ref update rules.
**Version policy:** semver for formal release names; no v0.x compatibility
promise is made during rapid iteration.

## Summary

This packet records the v0.3 adopted protocol surface: policy manifests,
conformance reports, strict CR evidence, review
trailers, release-tag validation, and protected ref-update rules.

## Preconditions

Before publishing a formal `v0.3.0` tag, a maintainer must:

- confirm the normative adoption CR and updated repository policy;
- run `scripts/ugs_check.sh --format json` and preserve its passing report;
- run `scripts/validate_repo.sh` and all CR validators;
- verify every commit from the recovered signed fast-forward boundary with
  trusted SSH signatures; the earlier unsigned draft sequence remains outside
  the high-trust claim;
- verify the signed annotated tag locally with `scripts/validate_release_tag.sh`;
- confirm rollback and migration notes are complete; and
- push the tag without deleting or replacing any existing formal tag.

## Compatibility

This is pre-1.0 rapid-iteration work. v0.3 schemas, commands, reports, and
validator behavior may change without compatibility guarantees with v0.2.
Accepted v0.2 history is not invalidated by this adoption.

## Rollback

Before publication, revert the release-packet change through a new signed CR.
After publication, never rewrite or replace the tag; publish a superseding
patch release with corrected notes.
