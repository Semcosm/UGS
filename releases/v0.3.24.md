# UGS v0.3.24

This release separates UGS Core governance from hosting-platform mappings.

Core validation now works with Git-native history, CR records, hooks, signed
commits, signed tags, and explicit repository identity without requiring
GitHub APIs, event files, URLs, or `.github` files. GitHub PR, Actions, and
Releases behavior is provided through explicit adapters. Bootstrap validation
also covers a GitHub-free baseline consumer and adapter-enabled profiles.
